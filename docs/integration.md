# 推理 / 语音 / 记忆 / 搜索接入说明

## 1. 推理模块接入

### 1.1 APK 内部分布
- `lib/arm64-v8a/`：NDK 编译的推理库 `.so` 及依赖库。
- `assets/runtime-config.json`：引擎、模型路径、上下文长度、线程数、内存上限等配置。
- JNI 加载代码：Java/Kotlin 层通过原生接口调用 `.so`。

### 1.2 外置模型目录（头显本地存储）
```
/storage/emulated/0/DayDream/
├── models/            # GGUF 权重
├── tokenizer/         # 分词器
├── memory/           # 对话历史、角色设定、记忆索引
└── config.json
```

### 1.3 启动加载流程
1. 检查外部存储读取 / 写入权限。
2. 校验模型权重与分词器文件是否存在；缺失则提示放入模型文件，或回退云端。
3. 加载权重与分词器，初始化推理上下文。
4. 接收输入文本，组装提示词上下文，推理生成回复。
5. 回复交给 UI、TTS、记忆模块。

## 2. 离线语音模块（定稿：端侧离线，不调用云端语音）

### 2.1 STT（离线语音识别）
- 麦克风采集语音 → 端侧离线识别为文字 → 送入对话输入。
- 不依赖云端语音服务；离线环境可正常工作。
- 接入点：原版语音录制逻辑与输入框之间。

### 2.2 TTS（离线语音合成）
- 模型回复文本 → 端侧离线合成语音播放。
- 文本同时传给口型动画触发点；复用原版已有口型动画事件。
- 注意：离线 STT / TTS 模型与推理模型共享内存池，需计入整机内存预算。

## 3. 记忆模块

### 3.1 短期记忆
- 当前会话对话历史，随上下文一并送入提示词。
- 会话结束可归档到长期记忆目录。

### 3.2 长期记忆
- 用户偏好、角色设定、关键对话本地落盘。
- 文件位于外置 `memory/` 目录，APK 更新不覆盖。

### 3.3 向量检索（可选）
- 对历史对话建立索引，召回与当前问题相关的片段补充进上下文。
- 未启用时按顺序拼接会话历史即可。

## 4. 联网搜索模块（可选，默认关闭）
- 离线主链路不发起网络请求；该模块仅在需要联网扩展时启用。
- 流程：Router / 规则判断是否检索 → 取资料摘要 → 拼入提示词上下文 → 模型基于资料生成回复。
- 约束：搜索接口需可用授权；网络请求需处理权限、线程、安全配置；搜索结果仅作上下文参考。

## 5. 推理模式说明（定稿：local 默认）
- 配置项 `inference_mode`：`local`（本机 llama.cpp）；`cloud` 为可选扩展，默认 `enabled: false`。
- 本机链路不依赖云端；本地模型缺失或加载失败时，按配置决定是否提示，不自动强制走云端。
- 切换 GGUF 模型文件即可更换模型，引擎代码不变（GGUF 格式一致前提下）。
