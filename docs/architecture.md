# 架构细节与模块边界

## 1. 模块划分

### 1.1 调度层 Router
- 接收用户输入（文字 / 语音识别结果）。
- 按 `runtime-config.json` 选择本地或云端推理。
- 本地模型缺失、加载失败或内存不足时，可回退云端。
- 把模型回复交给 UI 渲染、TTS 与口型模块。

### 1.2 本地推理模块
- 推理库（`.so`）打包在 APK 的 `lib/arm64-v8a/`。
- 权重与分词器外置到头显本地存储，不进入安装包。
- 输入：提示词上下文；输出：模型回复文本。

### 1.3 云端推理模块
- 通过网络请求对接对话接口。
- 作为本地内存不足时的备选；原版云端后端是否在线需解包 / 真机确认。

### 1.4 语音模块
- **STT**：麦克风语音 → 文字，送入对话输入。
- **TTS**：回复文本 → 语音；同时把文本传给口型动画触发点。
- 模块内存占用需与推理模型一起做预算。

### 1.5 记忆模块
- **短期历史**：当前会话对话记录，随上下文送入提示词。
- **长期记忆**：用户偏好、角色设定、关键对话本地落盘。
- **向量检索（可选）**：从历史片段中召回与当前问题相关的记忆。

### 1.6 联网搜索模块
- 判断问题是否需要外部资料。
- 调用搜索接口取结果摘要，拼入提示词上下文。
- 模型基于检索资料生成回答，避免无依据编造。

## 2. 数据流

```
用户语音 / 文字
    │
    ├─ STT（语音转文字）
    ▼
输入文本 → Router（本地 / 云端选择）
    │
    ├─ 本地推理：GGUF 权重 + 分词器
    └─ 云端推理：API 请求
    ▼
回复文本 → UI 对话气泡
    │
    ├─ TTS 语音播放
    └─ 口型动画触发
    ▼
对话历史 / 长期记忆写入本地存储
```

## 3. 模式切换规则
- 默认模式由配置 `inference_mode` 决定（local / cloud）。
- 本地启动失败（模型文件缺失、内存不足、加载报错）→ 按配置回退云端。
- 切换模型只需替换外置 GGUF 文件，APK 代码无需重编（前提是引擎格式一致）。

## 4. 存储边界
- 模型权重、分词器、记忆文件均位于头显本地存储目录。
- APK 只携带推理库、加载代码与配置文件。
- 记忆与对话默认不上传外部服务。
