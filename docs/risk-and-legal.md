# 风险、版权与合规清单

## 1. 使用边界
- 逆向修改、重打包、回装仅限本人合法持有的原版副本，用于个人研究。
- 修改后的安装包不得上架应用商店、不得对外分发、不得二次发布。

## 2. 版权素材
- Emma 角色模型、服装、场景、动画素材归原应用版权方所有。
- 不得提取原素材对外分享、二次修改发布或用于其他项目。

## 3. 模型许可
- Gemma、Qwen 等权重使用须遵守对应模型许可协议。
- 模型生成内容应保持健康合规，避免不当角色互动。

## 4. 技术风险
1. **签名校验**：重打包后签名变更，可能被客户端或系统校验拦截。
2. **内存预算**：4B 模型 + STT/TTS + 记忆 + 应用纹理同时驻留偏紧；先真机验证内存占用。
3. **云端后端**：原版服务器若下线，云端对话链路不可用；本地模型为替代方案。
4. **NPU 限制**：第三方应用对 XR2+ Gen2 NPU 驱动覆盖有限，实际以 CPU / GPU 运行。

## 5. 隐私
- 对话历史、用户偏好等记忆默认只存本机本地目录。
- 未经授权不得将对话或记忆上传到外部服务。

## 6. 待确认合规事项
- 目标模型权重的来源与许可条款。
- 搜索 / 语音接口的授权与调用条款。
- 分发范围仅限个人本机使用，不做公开传播。
