# Emma 3D 模型格式逆向确认与替换流程

> 原则：**先逆向确认原版 Emma 使用的模型格式、加载管线、骨骼与动画节点，再按同一格式制作替换模型**。不能在未确认加载器的情况下直接交付 glb / fbx；引擎不支持的格式不会被运行时识别。

## 1. 逆向确认顺序（依赖解包审计报告）

### 1.1 定位渲染引擎与模型加载器
1. 查看解包目录 `lib/arm64-v8a/`：原生库名称可提示引擎类型（如 Unity、Unreal、自研 XR 运行时）。
2. JADX / Smali 中搜索加载相关关键字：
   - 格式词：`glTF`、`glb`、`gltf`、`fbx`、`obj`、`mesh`、`model`、`avatar`、`character`、`vrm`。
   - 行为词：`loadModel`、`loadMesh`、`loadAvatar`、`spawnCharacter`、`Instantiate`、`SkinnedMeshRenderer`。
3. 记录：模型加载类、方法、传入的资源路径、文件后缀判断逻辑。

### 1.2 从资产文件反推格式
| 观察项 | 判断依据 |
|---|---|
| 资源目录文件后缀 | `.glb / .gltf / .fbx / .obj / .vrm / .assetbundle / .pak / .mesh` 等 |
| 资源打包方式 | Unity AssetBundle、Unreal Pak、自研打包；贴图 / 动画是否分离 |
| 二进制头特征 | glTF 开头 `glTF`；FBX 为二进制或 ASCII 头；OBJ 为文本顶点 / 面 |
| 动画与蒙皮引用 | 骨骼节点、BlendShape / MorphTarget、口型动画节点名称 |
| 角色挂载点 | 场景中角色 spawn / attach 方法传入的对象与变换节点 |

### 1.3 必须记录的替换对齐项
- **网格**：面数、缩放比例、原点位置、正向朝向。
- **骨骼蒙皮**：骨骼命名、层级、绑定姿势；替换模型骨骼命名需与原版一致。
- **表情 / 口型**：BlendShape（MorphTarget）节点名称、顺序；口型动画触发节点。
- **材质贴图**：贴图压缩格式、法线 / AO、材质参数；外观替换后材质要能被原版渲染器解析。
- **动画片段**：待机、跟随、口型、动作动画的挂载方式与触发事件。

## 2. 格式选择对照表（逆向结论出来后按原版格式对齐）

| 格式 | 运行时定位 | 适用场景 | 限制 |
|---|---|---|---|
| glTF / `.glb` | 跨引擎通用移动端格式 | 网格、材质、骨骼、动画打包；无 VRM 依赖时优先 | 原版引擎未内置 glTF 解析则不能直接用 |
| `.gltf` + `.bin` + 贴图 | 调试 / 检查节点用 | 文本可读，便于核对材质与骨骼 | 多文件，外置目录必须保持相对路径完整 |
| `.fbx` | DCC 交换格式 | Blender / Maya / Max 流程；动画骨骼蒙皮成熟 | 运行时通常不直接加载；交付前转为原版要求格式 |
| `.obj` (+ `.mtl`) | 静态网格 | 无骨骼的道具 / 场景摆件 | 不支持骨骼蒙皮与表情动画 |
| `.vrm` | 虚拟人扩展格式 | 人体骨骼、表情、视线；Companion 角色 | 基于 glTF；需运行时有 VRM 解析支持 |
| 引擎私有格式 | Unity AssetBundle / Unreal Pak / 自研 mesh | 原版引擎原生加载 | 只能由对应工具链导出；替换模型必须匹配私有规范 |

## 3. 替换实施步骤（确认格式之后）

1. **格式对齐**：按 §1 记录的原版格式导出替换模型；引擎私有格式时，使用原版配套导出管线。
2. **骨骼与节点对齐**：骨骼命名、层级、BlendShape 名称顺序与原版 Emma 保持一致；不一致会导致动画 / 表情挂载失败。
3. **材质贴图适配**：贴图压缩格式与显存预算按 Quest 3 共享内存约束；法线、AO 烘焙离线完成。
4. **外置放置**：角色外观放到 `characters/<character-id>/avatar/`；模型文件本地私有，不进入 Git。
5. **运行验证**：加载角色 → 检查网格显示、骨骼动画、表情口型、跟随动作；确认无材质丢失、无变形穿模。
6. **回退方案**：新模型加载失败时回退原版角色资源；不影响对话推理主链路。

## 5. 合规边界
- 原版 Emma 模型、服装、场景贴图仅限本人合法持有的副本本地研究；不提取对外分享、不二次发布。
- 仓库只保存格式约定、骨架代码与文档；模型二进制、贴图、动画文件不提交 Git。
